## Бот: ссылка за подписку

Бот проверяет, что ученица подписана на [@sashoshamath](https://t.me/sashoshamath), и только тогда присылает сайт.

1. В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username.
2. Скопируй токен.
3. Зайди в канал **@sashoshamath** → управление → администраторы → добавь бота. Ему достаточно права видеть участников (можно без права писать в канал).
4. В папке проекта:

```bash
cp .env.example .env
```

В `.env` вставь токен вместо `сюда_токен_от_BotFather`.

```bash
python3 -m pip install -r requirements.txt
python3 bot.py
```

5. Напиши боту `/start`. Сначала кнопка **забрать тренажёр**, потом проверка подписки, потом тренажёр открывается внутри Telegram.

Пока `python3 bot.py` крутится на компьютере, бот отвечает. Если ноут выключен — молчит.

## Чтобы бот работал всегда (Render)

1. Залей проект на GitHub (токен в `.env` туда не попадает).
2. Открой [Render Blueprint](https://render.com/deploy?repo=https://github.com/sashoshaa/sashosha-math), залогинься через GitHub.
3. В переменной `BOT_TOKEN` вставь токен от BotFather (тот же, что в `.env`).
4. Нажми Deploy. Когда сервис станет Live, бот отвечает круглосуточно.

После деплоя локальный `python3 bot.py` лучше выключить, иначе Telegram ругается на два запуска сразу.

Бесплатный тариф Render иногда засыпает без запросов. Если бот «тупит» с утра — напиши ему `/start` ещё раз или поставь бесплатный пинг на `https://ТВОЙ-СЕРВИС.onrender.com/health` раз в 10 минут (например [cron-job.org](https://cron-job.org/)).
